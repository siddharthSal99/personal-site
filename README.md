# personal-site

A simple personal landing page with links to GitHub, LinkedIn, a blog, a photography page, an art page, and maker projects.

## Structure

- `index.html` — landing page with links
- `blog.html` — placeholder blog page
- `photography.html` — placeholder photography page
- `art.html` — placeholder art page
- `maker-projects.html` — placeholder maker projects page
- `styles.css` — shared styles

## Usage

Static site, no build step. Open `index.html` in a browser, or serve the folder with any static file host (GitHub Pages, Netlify, Vercel, etc.).
