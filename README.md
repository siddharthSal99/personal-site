# personal-site

A simple personal landing page with links to GitHub, LinkedIn, a blog, and Instagram.

## Structure

- `index.html` — landing page with links
- `blog.html` — placeholder blog page
- `styles.css` — shared styles

## Usage

Static site, no build step. Open `index.html` in a browser, or serve the folder with any static file host (GitHub Pages, Netlify, Vercel, etc.).
